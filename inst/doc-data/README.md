# Documentation figures

The CSV files contain all displayed draws and numerical targets. The figure
source is `build-figures.R`; the vector PDF and HTML PNG outputs are in
`man/figures` in the package source. `provenance.dcf` records inputs and sampling
settings. The 60-dataset pilot uses the separate data in `validation/`.

These are fixed-input illustrations and bounded posterior checks. The pilot
and its uncertainty are described in the worked guide. They do not establish
general selection accuracy or repeated-dataset interval coverage.
